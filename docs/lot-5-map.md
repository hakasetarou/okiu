# 第5駐車場の座標マップ

既存の61枠を元画像の枠線に合わせて作り直しました。枠の追加・削除と番号変更は行っていません。
以前の座標の各枠の中央が、作り直した同じ番号の枠に含まれることを確認しています。
隣り合う枠の境界を共通化し、クリックする範囲を少し内側へ寄せて、枠同士の重なりを防いでいます。

[番号付きの確認画像](lot-5-map-preview.png)と画面のマップは、どちらも1〜61番です。
確認画像の緑は位置確認用です。画面では空き枠が緑、使用中が赤、自分の枠の外周が黄色になります。

## 維持した番号とエリア

| エリア | 番号 | 枠数 |
| --- | --- | ---: |
| 右側外周 | 1〜15 | 15 |
| 左下の外周 | 16〜22 | 7 |
| 左側外周 | 23〜33 | 11 |
| 上側の列 | 34〜40 | 7 |
| 中央の両面の列 | 41〜54 | 14 |
| 下側の短い列 | 55〜61 | 7 |
| 合計 | 1〜61 | 61 |

曲がり角の16番、入口付近の22番、左端の23番は、既存の形に合わせて個別に設定しています。
既存エリア間の空白や図面の端には、新しい枠を作っていません。
中央は41〜47番の列から、隣の列の48〜54番へ折り返す従来の番号順を維持しています。
下側の短い列も、従来どおり右下の55番から左上の61番へ続きます。

元画像の「61台」、DBの登録可能台数61台、駐車記録と番号体系のバージョン2は維持しています。
座標の再作成で位置を移し替える番号変更はないため、DB変更は不要です。

## 確認方法

1. `http://localhost:3000` を開き、`Ctrl + F5` で再読み込みします。
2. 第5駐車場の「マップから探す」を開き、地図をクリックして拡大します。
3. 枠線、番号、入出庫する場所の対応を確認します。

## 設定ファイルと再生成

| ファイル | 用途 |
| --- | --- |
| `public/images/img5.jpg` | 61台と記載された元画像。変更せず保存 |
| `docs/lot-5-map-rows.json` | 枠線の端の位置、既存番号の順番、再作成前の枠の中央位置 |
| `public/data/parking-spots/lot-5.json` | システムで使う61枠の座標 |
| `scripts/build-lot5-map.js` | 共通の処理で第5駐車場の座標を生成 |
| `docs/lot-5-map-preview.png` | 元画像に座標と番号を重ねた確認画像 |

```powershell
npm.cmd run build:lot5-map
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-parking-map-preview.ps1 -LotId 5
```

元画像が変わった場合や、公開座標を手動編集した場合、生成処理は上書きを止めます。
測定値から作り直して手動編集を置き換える場合に限り、生成コマンド末尾へ `-- --replace` を付けます。
生成コマンドはDBの台数や駐車記録を変更しません。
