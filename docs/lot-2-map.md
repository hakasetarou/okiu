# 第2駐車場の座標と確認方法

地図画像 `public/images/img2.jpg` の枠線に合わせて、205枠の座標を設定しています。
現地確認で木がある旧176番を除外し、旧177〜206番を新176〜205番へ繰り上げました。
画像から読み取った位置であり、現地測量によるものではありません。
枠番号はシステム用の1〜205番です。現地の番号との対応は未確認です。

[番号付きの確認画像](lot-2-map-preview.png)で位置と番号を確認できます。
緑色は座標の位置確認用で、現在の空き状況ではありません。

## 含めた場所・確認が必要な場所

- 閉じた通常の枠196か所と、下側で枠線が開いている9か所を合わせ、205枠としています。
- 列の端にある小さな三角形9か所、通路、右上の大きな四角い区画は座標に含めていません。
- 下側の146〜154番は、枠線の開いた先端を画像から推定しています。
- 上側中央の丸印は、利用者の現地確認で樹木だと分かりました。この場所（旧176番）は座標・台数から除外しています。**新176番は旧177番の場所**です。
- 元の図面は資料として保存しています。画面には `public/images/img2-system.svg` を使い、左上に205台と表示します。SVGは元画像に文字を重ねる形式で、画像の大きさと駐車枠の位置は維持しています。

## 番号の付け方

同じ列の番号は続けて付けています。両面に枠がある長い列は、片側をたどってから端で折り返します。

| エリア | 番号 |
| --- | --- |
| 左下の出入口付近 | 1〜16 |
| 南西側の短い列 | 17〜26 |
| 南西から1本目の長い列 | 27〜39 |
| 南西から2本目の長い列 | 40〜58 |
| 南西から3本目の長い列 | 59〜81 |
| 南西から4本目の長い列 | 82〜110 |
| 南西から5本目の長い列 | 111〜145 |
| 下側境界の9枠 | 146〜154 |
| 上側左の2列 | 155〜174 |
| 上側中央の2列 | 175〜187 |
| 上側外周 | 188〜205 |

## 画面での確認

1. `http://localhost:3000` を開き、`Ctrl + F5` で再読み込みします。
2. 第2駐車場の「マップから探す」を押します。
3. 必要に応じて拡大し、枠線と緑・赤のエリア、番号を確認します。
4. 空き枠を押すと入庫画面、自分の駐車枠を押すと出庫確認を開けます。

位置を微調整する場合は `http://localhost:3000/coordinate-editor.html` で第2駐車場を選びます。
公開座標が変更されたため、変更前の作業途中のデータは自動で引き継ぎません。古い206枠のファイルを読み込むと、旧番号へ戻るので使用しないでください。
編集したファイルを保存し、`public/data/parking-spots/lot-2.json` と置き換えてから再読み込みします。
入庫記録がある枠の番号を変える場合は、駐車記録との対応も合わせて変更する必要があります。

## 設定ファイル

- `public/data/parking-spots/lot-2.json`：画面が読み込む座標。位置は画像の幅・高さに対する0〜100の割合です。
- `public/images/img2.jpg`：変更前の元図面です。左上に206台と記載されています。
- `public/images/img2-system.svg`：左上の表記を205台にした表示用の地図です。
- `docs/lot-2-map-rows.json`：元画像上の測定値。`polygons` は枠ごとに測った四隅、`corners` は一列全体の四隅、`reverse` は番号の向きを反転する設定です。
- `scripts/build-parking-map.js`：第1・第2駐車場で共通の座標生成処理です。
- `scripts/build-lot2-map.js`：第2駐車場の座標と表示用地図を生成します。
- `migrations/009-lot2-remove-tree-space.sql`：205台への変更と駐車記録の番号変更を、一度だけ適用します。旧176番に駐車記録がある場合は、削除せずに停止します。

```powershell
npm.cmd run build:lot2-map
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-parking-map-preview.ps1 -LotId 2
```

元画像の変更や、座標ファイルの手動編集を検知すると生成を停止します。
手動編集を破棄して測定値から作り直す場合に限り、生成コマンドの末尾へ `-- --replace` を付けます。
今回の変更では、DBの収容台数も205台へ変更し、旧177〜206番の駐車記録を新176〜205番に対応させます。
古い画面から旧番号で入庫できないようにしているため、反映時はサーバーを再起動して画面も再読み込みします。

卒論には「現地確認により樹木のある1枠を除外し、第2駐車場の駐車可能台数を205台とした」と説明できます。
