## 公開前に確認する点

元の図面には「693台、うち軽専用78台」と書かれています。
一方、文字・斜線の区画・小さな三角形などを除き、四角い領域を画像から拾うと、数字付きの候補が703個あります。
領域数をそのまま駐車台数にすることはできません。線の途切れで2枠がつながった領域や、駐車可否が未確認の曲がり角が含まれるためです。
693台に合わせて候補を省くと、実際に使える場所を落とすおそれがあるため、公開前に図面と現地の対応を確認します。

- **候補80・555・582**：通常の枠より大きい場所や曲がり角です。図面では枠に見えますが、現地の駐車可否は未確認です。
- **候補172・283**：列の端の形が小さい場所です。通常の枠として使えるか確認が必要です。
- **候補586**：薄い区切り線があり、画像の白い領域を拾う処理では2枠がつながっています。正式な座標では分割する必要があります。
- **A・B**：候補586の下の2枠です。外周の線が途切れているため、703個の領域とは別に追加候補として表示しています。
- 軽専用78台がどのエリアか、元図面には位置の説明がありません。候補1〜79の左下の別区画を、確認なしに軽専用とは扱っていません。

候補数は実際の駐車可能台数を確定したものではありません。木や設備などで使えない場所があれば、候補番号で指定して修正できます。
