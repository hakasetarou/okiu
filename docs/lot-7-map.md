# 第7駐車場の暫定マップ

第3駐車場と同様に、まず画面で位置を確認して修正できるよう、104枠を暫定公開しています。
初回の102枠に、利用者が赤丸で指定した隣り合う2枠を追加しました。追加枠は新22・23番です。
元図面は93台と記載されていますが、現在の候補は104枠で、差の理由は未確認です。
104台は現地で確定した駐車可能台数ではありません。不要な場所の削除や、端の枠の位置調整を行って確定します。

[番号付きの確認画像](lot-7-map-preview.png)と画面のマップは、どちらも1〜104番です。
確認画像の緑は位置確認用で、現在の空き状況ではありません。
オレンジは列の端・曲がり角など、特に駐車可否と形を確認したい場所です。

## 座標の設定方法

第7駐車場は、片側が開いた枠線が多い図面です。区切り線の両端を記録し、隣り合う線の端をつないで1枠の範囲を作りました。
枠線にかからないよう、クリックする範囲を少し内側へ寄せています。通路・矢印・方位記号・小さな端の三角形は含めていません。
線がない端の閉じ方や、曲がった境界には推定を含みます。

元図面には軽専用の表記があります。どの枠までが対象かは未確認のため、専用区分や利用制限は設定していません。
番号はシステム用の連番であり、現地の番号との対応は未確認です。

## 番号の付け方

同じエリアの番号を続け、両面の列は端で折り返しています。
追加した2枠と、その下へ曲がる列はL字型の1エリアとして22〜34番を付けました。
旧102枠の位置と形は維持し、番号だけを以下のまとまりへ整理しています。

| エリア | 番号 | 枠数 |
| --- | --- | ---: |
| 左下の境界 | 1〜7 | 7 |
| 左側外周 | 8〜21 | 14 |
| 内側のL字型の列（追加2枠を含む） | 22〜34 | 13 |
| 上側の横一列 | 35〜42 | 8 |
| 右上の上側の列 | 43〜51 | 9 |
| 右上の中央・通路側（端で折り返す） | 52〜62 | 11 |
| 左下の短い列 | 63〜67 | 5 |
| 中央の両面の列（端で折り返す） | 68〜84 | 17 |
| 右側の境界 | 85〜92 | 8 |
| 下側の長い列 | 93〜104 | 12 |

確認画像でオレンジの21・24・43・51・92・93番は、端や曲がり角の枠です。21番の線のない上端、24番の広い端、92・93番の形などを現地と照らし合わせて確認してください。
図面の93台との差がこれらの枠だけで解消するとは限らないため、ほかの番号にも誤りがあれば指定できます。

前回の番号との対応は次のとおりです。今後の修正箇所は新しい番号で指定します。

| 変更前の番号 | 変更後の番号 |
| --- | --- |
| 1〜21 | 1〜21（同じ） |
| 22〜49 | 35〜62 |
| 50〜60 | 24〜34 |
| 61〜102 | 63〜104 |
| 今回追加した2枠 | 22・23 |

駐車中の記録もこの対応表で番号を移します。利用者・入庫時刻・退庫予定時刻・枠の使用状況は維持します。

## 画面で確認する

1. `http://localhost:3000` を開き、`Ctrl + F5` で再読み込みします。
2. 第7駐車場の「マップから探す」を開き、地図をクリックして拡大します。
3. 枠線と座標、番号を確認します。「○番を削除」「○番を右へ」のように修正箇所を指定してください。
4. 緑の枠から入庫、自分の枠から出庫確認を開けます。使用中は赤、自分の枠の外周は黄色です。

微調整は `http://localhost:3000/coordinate-editor.html` でも可能です。第7駐車場を選び、保存した `lot-7.json` を公開座標と置き換えます。
入庫記録がある枠の番号を変える場合は、駐車記録にも同じ変更が必要です。

## ファイルと再生成

| ファイル | 用途 |
| --- | --- |
| `public/images/img7.jpg` | 93台と書かれた元図面。変更せず保存 |
| `public/images/img7-system.svg` | 元図面を埋め込み、左上を「暫定104台」にした表示用地図 |
| `docs/lot-7-map-rows.json` | 枠線の両端の位置、列の向き、番号の範囲 |
| `docs/lot-7-map-rows-v1.json` | 変更前102枠の測定値。位置を維持したことの確認用 |
| `docs/lot-7-renumbering-v2.json` | 旧102枠から新番号への対応表と、追加番号22・23 |
| `public/data/parking-spots/lot-7.json` | 画面で使用する座標。位置は画像に対する百分率 |
| `scripts/build-lot7-map.js` | 共通の処理で座標と表示用地図を生成 |
| `migrations/012-lot7-provisional-map.sql` | 初回の暫定102台と表示用地図をDBへ反映 |
| `migrations/013-lot7-area-numbering.sql` | 104台へ変更し、既存の枠の状態と入庫記録を新番号へ移す |

```powershell
npm.cmd run build:lot7-map
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-parking-map-preview.ps1 -LotId 7
```

元画像が変わった場合や、公開座標を手動編集した場合、生成処理は上書きを止めます。
手動編集を破棄して測定値から作り直す場合に限り、生成コマンド末尾に `-- --replace` を付けます。
DB変更は `npm.cmd run migrate` で一度だけ適用します。初回公開の012では、位置を判断できない旧記録があれば停止します。
今回の013では、旧1〜102番の記録を対応する新番号へ移します。想定外の番号、重複する状態、変更前の台数の不一致があれば、記録を維持して全変更を取り消します。
適用後はサーバーを再起動します。旧番号体系の画面からの入庫は拒否し、再読み込みを案内します。
