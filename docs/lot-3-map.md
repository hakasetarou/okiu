# 第3駐車場の暫定マップ

利用者の「まず反映して、マップを見て誤りを指摘する」という指示に基づき、706枠を暫定公開しました。
[番号付き確認画像](lot-3-map-preview.png)と実際の画面は、どちらも1〜706番です。
確認画像の緑は位置確認用で、現在の空き状況ではありません。

元図面には「693台、うち軽専用78台」とあります。現地で確定した台数ではなく、今回の706台も位置確認のための暫定設定です。
図面の693台へ無理に合わせず、確認後に不要な枠を削除したり、見落とした枠を追加したりします。
軽専用78台の場所は未確認のため、特定のエリアを軽専用として扱っていません。

## 反映した内容

- 公開前の703領域を基に、候補586を新586・587番の2枠に分割しました。
- 追加候補A・Bを新588・589番として組み込みました。
- 旧候補587〜703番は、新590〜706番です。前半1〜585番は変えていません。
- まとまったエリア内で連番にし、同じ枠番号が重ならないようにしています。
- 第5駐車場と同じ処理で緑は空き、赤は使用中、自分の枠の外周は黄色です。緑の枠から入庫、自分の枠から出庫できます。

確認画像のオレンジの外周は、特に現地の形・駐車可否を確認したい場所です。
80・555・582番は広い端や曲がり角、172・283番は小さい列の端、588・589番は外周線が開いている場所です。
これらも利用者の指示に従い、まず暫定マップに含めています。

## 画面で確認する

1. サーバー起動後にブラウザで `Ctrl + F5` を押します。
2. 第3駐車場の「マップから探す」を開き、地図をクリックして拡大します。
3. 不要な枠は「○番を削除」、位置のずれは「○番を右へ」など、現在の番号で指定してください。
4. 枠が足りない場所は、付近の番号と位置が分かる画像で指定できます。

枠を削除して番号を繰り上げる場合、駐車記録にも同じ変更が必要です。現地の番号との対応は未確認です。

## ファイルと再生成

| ファイル | 用途 |
| --- | --- |
| `public/images/img3.jpg` | 元図面。変更せず保存 |
| `public/images/img3-system.svg` | 元図面を埋め込み、左上を「暫定706台」にした表示用画像 |
| `docs/lot-3-map-rows.json` | 元画像の位置で記録した706枠の測定値 |
| `public/data/parking-spots/lot-3.json` | システムが読み込む座標。位置は画像に対する百分率 |
| `scripts/build-lot3-map.js` | 共通の座標生成処理と表示用画像の生成 |
| `migrations/010-lot3-provisional-map.sql` | 台数と表示用地図をDBへ反映 |

```powershell
npm.cmd run build:lot3-map
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-parking-map-preview.ps1 -LotId 3
```

元画像が変わった場合や公開座標を手動編集した場合、生成処理は上書きを止めます。
手動編集を破棄して測定値から作り直す場合に限り、生成コマンド末尾に `-- --replace` を付けます。
DB変更は `npm.cmd run migrate` で一度だけ適用します。第3駐車場に駐車記録があれば削除せず停止します。
反映前の番号体系で開いた画面からの入庫は拒否し、再読み込みを案内します。

公開前の703領域の資料は `lot-3-map-review-*` として残しています。現在の修正指示には暫定706枠の番号を使用してください。
