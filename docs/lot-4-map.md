# 第4駐車場の座標と確認方法

元図面 `public/images/img4.jpg` の枠線に合わせて、78枠の座標を設定しました。
図面に書かれた78台と一致するため、設定台数と左上の表記はそのままです。
画像から読み取った位置であり、現地測量によるものではありません。現地の番号との対応は未確認です。

[番号付きの確認画像](lot-4-map-preview.png)で位置と番号を確認できます。
確認画像の緑は位置確認用で、現在の空き状況ではありません。

## 番号の付け方

同じ列の番号を連番にし、両面に枠がある列は端で折り返しています。通路・入口・方位記号は枠に含めていません。

| エリア | 番号 |
| --- | --- |
| 左下の外周（入口側から上へ） | 1〜13 |
| 左上の外周（左下から右上へ） | 14〜23 |
| 右上の折れ曲がった列 | 24〜31 |
| 中央右の2列 | 32〜51 |
| 中央左の2列 | 52〜69 |
| 右側の短い2列 | 70〜78 |

## 画面で確認する

1. `http://localhost:3000` を開き、`Ctrl + F5` で再読み込みします。
2. 第4駐車場の「マップから探す」を開き、地図をクリックして拡大します。
3. 枠線と座標、表示された番号を確認します。
4. 緑の枠から入庫、自分の枠から出庫確認を開けます。使用中は赤、自分の枠の外周は黄色です。

不要な枠や位置のずれは「○番を削除」「○番を右へ」のように番号で指定できます。
微調整は `http://localhost:3000/coordinate-editor.html` でも可能です。第4駐車場を選び、編集して保存した `lot-4.json` を公開座標と置き換えます。
入庫記録がある枠の番号を変更する場合は、駐車記録にも同じ番号変更が必要です。

## ファイルと再生成

| ファイル | 用途 |
| --- | --- |
| `public/images/img4.jpg` | 元図面。変更せずそのまま表示 |
| `docs/lot-4-map-rows.json` | 元画像上で測った枠の位置と番号の並び |
| `public/data/parking-spots/lot-4.json` | 画面で使う座標。位置は画像に対する百分率 |
| `scripts/build-lot4-map.js` | 共通の座標生成処理を使って78枠を生成 |
| `migrations/011-lot4-map-publication.sql` | 台数と駐車記録を公開前に確認。既存の記録には書き込まない |

```powershell
npm.cmd run build:lot4-map
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-parking-map-preview.ps1 -LotId 4
```

元画像が変わった場合や、公開座標を手動編集した場合、生成処理は上書きを止めます。
手動編集を破棄して測定値から作り直す場合に限り、生成コマンド末尾に `-- --replace` を付けます。
公開時は `npm.cmd run migrate` で、旧番号だけの駐車記録がないことを確認して適用済みとして保存します。
駐車記録があれば削除せず停止します。サーバー再起動と画面の再読み込み後に、新しい番号で利用できます。
